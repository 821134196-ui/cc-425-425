# 商场停车无感扣费异常复核平台（虚构演示）

一个零依赖（仅 Python 3.11 标准库）的本地演示平台，覆盖商场停车无感支付的
**进出场识别 → 计费 → 自动扣费 → 异常复核 → 人工放行 / 退款** 全链路。
所有车牌、订单号、优惠券、金额均为**虚构数据**，支付由进程内模拟适配器完成，
不发起任何真实网络请求。

## 单条命令启动

```bash
python3 run.py
# 等价于：python3 -m parking_review.demo
```

启动时会自动重置 `./data/`、生成完整的进出场/扣费/复核样例并打开 Web 服务：

- 地址：<http://127.0.0.1:8000/>
- `python3 run.py --seed-only` 只生成样例不启动
- `python3 run.py --port 8080` 指定端口

演示岗位（登录 PIN）：

| 账号 | 岗位 | 权限 |
|---|---|---|
| `monitor01` / `1001` | 监控员 | 只读：车道、记录、异常查看 |
| `reviewer01` / `2002` | 复核员 | 异常复核、重试扣费、人工放行 |
| `cashier01` / `3003` | 收费员 | 退款 |
| `admin01` / `9009` | 管理员 | 全部权限 + 发布规则版本 |

## 六个交付页面

1. **车道监控** `/`：横向车道带展示车道状态（在线/离线/维护、设备时钟偏移、最新设备时间与最近识别消息）。
2. **停车记录** `/records`：按入场时间排列的「入场 → 出场 → 结算」时间线，金额列固定宽度。
3. **异常队列** `/cases`：六类异常分待复核/复核中/已处置，短标签 + 完整原因同时呈现。
4. **规则版本** `/rules`：免费时长 / 小时费率 / 单日封顶的版本时间线；管理员可发新版。
5. **人工放行** `/releases`：放行台账 + 新建放行（必须选原因、填说明、关联本地证据图片）。
6. **退款台账** `/refunds`：订单退款操作与退款流水，一单一次、幂等。
7. （附）订单详情 `/orders/<id>`：不可变**计费快照**，含逐自然日切片与抓拍证据。

界面配色：浅混凝土灰 `#d9d9d7`、黑色 `#1a1a1a`、青绿色 `#14b8a6`。

## 业务规则

- **设备时间为准**：入/出场记录按车道设备时间排序；车道可配置独立时钟偏移。
- **绑定才扣费**：车辆绑定有效支付方式（支付宝/微信/银联，虚构）才允许无感自动扣费。
- **计费**：免费时长（仅入场当日抵扣一次）→ 超出部分不足 1 小时按 1 小时 →
  每自然日独立封顶 → 跨日按日切片合计；优惠券出场时点校验（现金券/折扣券）。
- **规则版本**：按**入场时间**选版本；已结算订单保存完整计费快照 JSON，
  之后修改/发布规则**不重算**历史订单。
- **六类异常**：车牌识别不一致、重复出场、支付失败、无牌车、跨日停车、优惠券失效。
  其中跨日/券失效为事后复核（不阻断出场结算），其余类型拦截自动扣费。
- **去重与幂等**：
  - 相同 `message_uid` 的重发消息只处理一次；
  - 同一车辆两条出场消息（30 分钟窗口）判定重复出场，**绝不二次扣费**；
  - 退款同一订单只允许一次，重复提交返回同一退款单（DB 唯一约束兜底）。
- **人工放行**：必须选择原因、填写说明并关联本地抓拍证据文件（纯标准库生成 PNG）。

## 存储

- SQLite：`./data/parking.db`（车道、车辆、规则版本、会话、消息、订单、计费快照、异常、放行、退款）。
- 本地证据图片：`./data/evidence/normal|review/*.png`。
- 支付：`parking_review/payment.py` 进程内线程安全模拟网关
  （`ok` / `fail_once` 首次失败重试成功 / `declined` 始终拒绝）。

## 测试（38 个，均为标准库 unittest）

```bash
python3 -m unittest discover -s tests -v
```

覆盖：

- 计费边界（免费时长边界、向上取整、单日封顶、跨日切片、版本选择、券各失效态）；
- 消息去重（uid 幂等、重复出场只扣一次、30 分钟外重入算新会话、设备时钟偏移）；
- 规则快照（历史订单不随新版重算、新单按新版、快照含逐日切片）；
- 退款幂等（一单一次、未付不可退、网关层幂等）；
- 岗位权限（四岗位读/复核/放行/退款/发版边界，放行证据强制校验）。

## 代码结构

```
parking_review/
  db.py          SQLite schema 与连接
  billing.py     计费引擎（纯函数）：免费/取整/封顶/跨日/券/快照
  services.py    消息接入、去重、异常路由、结算、复核、放行、退款、发版
  payment.py     进程内模拟支付适配器
  evidence.py    纯标准库 PNG 抓拍证据生成
  web.py         http.server Web 界面与操作端点（签名 cookie 登录）
  demo.py        虚构样例时间线 + 启动器
  world.py       测试夹具
tests/           五组单元测试
run.py           单命令入口
```

# 商场停车无感扣费异常复核平台（虚构演示系统）

一个零第三方依赖（仅 Python 3.10+ 标准库）的停车无感扣费与异常复核演示平台。
**所有停车场、车牌、车道、人员、订单、金额、证据图片均为虚构数据。**

## 一条命令启动

```bash
./run.sh --reset        # 重建样例数据并启动（http://localhost:8000）
./run.sh                # 保留数据直接启动；PARKING_PORT=9000 可改端口
```

启动后自动生成覆盖全部场景的样例（跨日停车、优惠券抵扣/失效、支付失败、
车牌识别不一致、无牌车、重复出场、人工放行、退款）。

## 六个交付视图

1. **车道监控** — 停车场下的横向车道带（入口/出口、最近设备事件、告警红色条带），
   下方消息表严格按**车道设备时间**排序；
2. **停车记录** — 按入场时间 → 结算时间排列，金额列为固定宽度等宽数字；
   点击任意行打开会话抽屉（入场→结算时间线、进出场抓拍证据、计费快照）；
3. **异常队列** — 六类异常短标签（牌异/重出/付败/无牌/跨日/券失）+ 完整文字说明，
   可复核处理、重试扣款、人工放行；
4. **规则版本** — 免费时长/计费单位/单价/自然日封顶的版本台账，ADMIN 可登记新版本；
5. **人工放行** — 单号、**必选原因 + 完整说明 + 本地证据文件**、操作人；
6. **退款台账** — 一单一次，重复提交幂等返回原退款单。

## 计费口径

- 规则按**入场时间**选取当时生效版本；已结算订单把规则与计算过程存为
  JSON 快照（`orders.rule_snapshot` / `fee_detail`），规则之后修改**不重算**；
- 免费时长 + 免费分钟券顺序扣减；按自然日切分，每段按计费单位**向上取整**，
  每自然日独立适用封顶金额；立减券在总额扣减，最低 0 元；
- 车辆必须绑定**有效**支付方式才会自动扣费；失败（模拟令牌以 `FAIL:` 开头）
  或无有效方式进入复核，可补绑后重试。

## 消息去重

- 车道消息以 `msg_uid` 为去重键，重复推送直接返回首条结果；
- 同一车辆第二条出场消息若对应会话已完成出场，进入 `DUP_EXIT` 复核，
  **不新建订单、不二次扣款**。

## 存储与外部依赖

- SQLite（`data/parking.db`）：车道、会话、订单、计费快照、复核、放行、退款等全部台账；
- 本地文件（`data/evidence/*.svg`）：虚构识别抓拍证据，放行必须关联目录内真实文件（防路径穿越）；
- 支付：进程内模拟适配器 `parking/payment.py`，无任何真实网络交易。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：免费时长/取整/封顶/跨日/优惠券**计费边界**、uid 去重与重复出场不扣费、
规则版本选择与快照不重算、退款一单一次**幂等**、四岗位**权限矩阵**及
放行原因/证据校验（共 38 例）。

## 目录结构

```
parking/
  config.py    路径配置（可用环境变量覆盖）
  db.py        SQLite schema 与连接
  billing.py   纯函数计费引擎（版本/免费/取整/封顶/券/跨日）
  payment.py   进程内模拟支付适配器
  auth.py      四岗位权限矩阵
  service.py   消息接入、去重、结算快照、复核、放行、退款
  queries.py   六个视图的只读台账查询
  evidence.py  虚构 SVG 抓拍证据生成
  seed.py      样例数据生成（python -m parking.seed --reset）
  server.py    stdlib HTTP 服务 + JSON API + 静态页面
  web/static/  界面（浅混凝土灰 / 黑 / 青绿色）
tests/         unittest 测试
run.sh         单条本地启动命令
```
